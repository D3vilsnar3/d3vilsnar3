Trajectus IVR

An IVR-based chatbot handling medical query calls, built on Google DialogFlow. Delivered as outsourced work for Computer Instruments (CI) — voice-first, not text, which is a different failure surface entirely: no typing to fall back on, no way to re-read a misheard prompt, and a caller who's often calling about something urgent.

  • Google DialogFlow voice IVR for medical query handling
  • Voice-first design, not a text chatbot adapted to phone calls
